# AllTradeBD Static Website

A simple, hosting-friendly trade/import landing page built with plain HTML, CSS, and JavaScript. It is designed to run on shared cPanel/PHP hosting without a build step.

## Deploy

Upload these files to your hosting `public_html` directory:

- `index.html`
- `styles.css`
- `script.js`

No database, Node.js, or PHP setup is required.
